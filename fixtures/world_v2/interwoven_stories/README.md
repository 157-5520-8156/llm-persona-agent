# P2交织故事测试材料

两份全新虚构试稿，只用于隔离的历史测试世界，**未成为当前生产历史**。
第一条线追踪记录别人、表达边界与作品用途；第二条线追踪家用工具、借用与后来获知。
两线交集为2025-04-19同一次义卖/交夹子及其后续，拍照与交夹子可以属于同一义卖场景，但其具体事实不可互相替代，也不能把2026年的告知当作2025年当场已知。

Gold判定：
- 两次叙述的“交出同两只夹子”应识别为同一发生；来源与各自知情/回想时点保留。
- 2026-01告知夹价目纸、告知照片印传单是后来发生/后来获知，不能归并为2025-04的交夹子或拍照。
- 2025-06视角不得知道传单用途；现在回看可以同时保留当时的失落和后来得到的信息。
- 不得确定实际印制日期、份数、网络平台、夹价目纸次数、夹子已归还、人物已和解或今后必然怎样选择。
- 原稿源段必须完整保留。提取记录数与随机ID不是质量指标；覆盖、事件身份、知情时点与遗漏/虚构分开评价。
- 同一次源稿/捕获恢复无新请求；另开独立抽取才算转换稳定性样本。

后续结构化底稿验收还需补：从不同故事入口读到同一发生；一线已经成立的后果在另一线相关
情境中持续可见；交叉处的自主拒绝/延期使依赖的未来机会失效或改变；暂不相交的生活也能继续。
这些是待扩展用例，不是当前两篇固定前史已证明的运行能力；不以强制交叉配额或固定结局实现。
