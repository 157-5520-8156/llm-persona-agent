# University 线交叉审阅

审阅对象：`university.json` 与 `university.md`；对照共同大纲、旧12条日常前史及《你到了跟我说》。这是创作编辑审阅，不是生产前史批准。

结构核对：U01—U20共20个唯一ID，深度配额为6轻、8中、6深，日期范围在2024年9月至2026年7月内。U04按接口只写周祺知道“没选上”，没有让她知道稿件内容或嘉禾私聊。未发现与旧12条记录或嘉禾17条事件的实质性重写；U08冰棒和旧冰棍记录是不同年份、不同事件。以下问题值得修订。

1. **U16日期与生日台词冲突。** 场景时期精确到2026-04-12（知栀生日），正文却说“生日早过了”。最小修改：把场景日期放宽为2026-04-13至2026-04-19，保留“生日那周”；或者把台词改成不表示生日已经过去的话。共同大纲要求新增生日场景沿用4月12日，若作者本意是当天，应改台词而不是日期。

2. **U14正文含有时期之外的情节。** JSON时期从2025-12-01开始，叙事却说周祺“在十一月底问”是否再办活动。最小修改：把准备开始日期扩至2025年11月下旬，或删去“十一月底”并让询问落在12月。U13已在10—11月完成重新约定及分工，建议把U14直接接成活动日前后的执行场景。

3. **U13和U14重复启动同一轮活动。** U13已经写周祺提议再办、知栀同意、缩小范围并划分分工；U14又从周祺重新询问、知栀再次同意和提出先讲分工开始。最小修改：保留U13的恢复决定，让U14从桌子少一张、现场改摆放图切入，省去第二次“要不要再办/先讲分工”。

4. **U15和U20重复同一只旧帆布袋的处理。** 两条都是没人要、周祺说自己已有两个、知栀把袋子带走。U15明确是U14同一场活动的收尾，U20又在最终活动重复相同物件和对话，容易被记作同一个事实两次。最小修改：U20删掉帆布袋段，保留“最后一次活动实际办完、秋天未承诺”的收尾；若想保留物件链，则明确U20拿出的是另一只袋子并给出能区分的细节。

5. **多个场景和记忆把同一段经过重复写了两遍。** U02在问路、截图后再次完整复述截图和备注；U06重复“先试摆”的约定；U07重复便签卷角；U08重复起球外套的问答及收摊冰棒；U13重复活动范围、分工和拍清单；U17重复耳机被拒收及收摊对话；U19重复分袋和是否继续的问答；U20记忆末尾又重复“最后一杯饮料”和“不替两人承诺”。最小修改：每条保留一遍完整动作链，把独有的后续动作并入同一段；记忆正文不要再复制同一组对白或结果。

6. **U07记忆加入原场景未建立的招募状态。** 记忆说“她们还没招齐人”，但正文只写便签和收纳标准，并未说明当时招募是否完成；U06还写过她们已经向熟人发出活动消息。最小修改：删去“还没招齐人”，只保留“也没决定活动具体怎么摆”这一类正文能够支持的内容，或在正文补出知栀确实知道的招募进度。

7. **U06把缺盖杯的使用风险写得过于绝对。** 周祺担心别人会以为杯子能装水，但缺盖杯仍能盛水；问题应是携带时容易洒，或物品状态容易被误解。最小修改：将对象说成“原本带盖的随行杯，盖子丢了”，并把争点落到能否安全携带/是否要明确缺盖，而不是暗示它客观不能装水。

8. **六条深场景均明显短于大纲长度目标。** U06、U10、U11、U14、U15、U20的叙事分别约324、333、303、321、336、302字符；大纲给深场景的参考是约450—750字。现稿多处后加重复段落仍未达到这一范围，说明当前较像摘要。最小修改：先删除重复，再只给关键转折补足当场动作、对话和实际后果；无需为达字数增加内心总结。深度记忆都非空且在约200字以上，没有发现把正文没有的事件结果塞进这些记忆的普遍问题。
