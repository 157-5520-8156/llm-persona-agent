# 本次认知与历史主观状态的共同边界

显式聊天审核 v20 让作者、两名独立读取器、完整来源审核及同角色纠正使用
`private-cognition-scope.1`。角色可以在本次生成中形成和修正私密认知；独立先前
阶段、持续或反复的主观历史仍需要已接受记录。语法时态不决定权限，外部事件、
已完成通信、习惯及共同经历继续分别审核。没有本地关键词分类或固定角色话术。

作者原来的“immediate retrospective continuity”过于宽泛，旧读取器却把过去主观
状态一律要求历史记录。本次同时收窄前者并精确限定后者。它修复了合同漂移，但
没有证据证明该漂移导致了此前全部聊天超时。

- v20 使用意义读取器 v16、来源审核 v4；原协议 1–19 不改编译语义。
- 完整原气泡和两份独立读法仍全部提交来源审核；空事实列表也不能跳过审核。
- 继承 v19 的 Fact 精确值、主体、时间和权限核验，不把整段观察当作接受值。
- 明确拒绝仍交回同一角色一次重选；不确定或失败继续是技术失败。
- 来源模型可通过测试 CLI 单独配置，不再误用角色模型配置替代它。
- Affect 引用只改可逆呈现，九份旧请求离线减少 3,329–4,025 字节；未证明真实
  token 或延迟改善，不能据此预测月费。

本地测试验证编译、权限、完整性、纠正反馈及冷回执；不证明模型会正确理解所有
句子。显式试验与生产发布资格分别记录在当前发布状态页，默认配置没有启用 v20。
