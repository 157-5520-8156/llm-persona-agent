# 发布会视觉风格 v5：纸面 3D 镜头（已获用户认可）

> 2026-11-05 用户认可样片：`output/bilibili-launch-v4/out/paper-sample-25d.mp4`
> 实现参考：`output/bilibili-launch-v4/src/scenes/PaperSample25D.tsx`
> 认可的是**画面风格与运镜**；样片里的**内容不合格**（见第 3 节），不得照抄。

## 1. 要保留的风格

- **舞台**：一整张暖纸色方格工作台（`#F2EEE6` 底、细网格），所有内容都是放在桌面上的纸卡、聊天卡、便签、照片。
- **镜头**：CSS 3D 透视相机（`perspective` + `rotateX/Y/Z` + `translate3d`）在桌面上推、摇、俯冲、拉远；桌面本身倾斜 16°–32°，绝不正对屏幕平放。
- **层次**：卡片按 Z 高度分层（桌面 0 / 卡片 30–45 / 弹起的重点 55–65 / 结论 80+），越高阴影越大。
- **动作**：卡片弹入、印章砸下、重点词从卡片上浮起、SVG 线把两张卡连起来、卡片 180° 翻面露出 Dashboard 实录。
- **节奏**：旁白先合成并去首尾静音，句间约 0.13s；镜头关键帧按句子时间点排，一句话说完就换动作，不留等待。
- **字**：全部是 DOM 文字，永远清晰；字幕底部深色胶囊，重点词橙色。
- **不用**：Three.js 几何体拼建筑、人物、房间。

## 2. 色彩语义（沿用）

- 橙 `#FF6A2B`：真实发生过、有出处的内容。
- 灰色虚线：编出来的、不存在的内容。
- 红：仅用于“拦下”的印章。

## 3. 样片的内容问题（下次必须避免）

1. **黑话**：“小票”“词元”“账本”“溯源”“ZONE 01”“AUDIT”“PROVENANCE”等，观众不懂，也不需要懂。
2. **为密度堆细节**：桌面标题条、分区编号、英文标签都没有被旁白提到，只是装饰。
3. **编造字段**：“SHA-256 VERIFIED”“08:42 卖完”“违章电器”“角色心绪：小怨念”不是真实记录，属于伪造证据，严禁出现。
4. **素材不相干**：贴在桌边的两张自拍照与剧情无关。需要照片时，只用角色生图链路“她自己拍的”与剧情直接相关的图（例如她买到的糖包和豆浆）。
5. **例子 AI 味重**：台词像在答题。优先用真实发生过的版本（她主动提起早饭），而不是“诱导提问—拒绝编造”的测试题。

## 4. 画面元素准入规则

画面上每一个元素必须满足其一，否则删除：

- 旁白正在说它；
- 它是旁白所说内容的直接证据（聊天原文、Dashboard 实录、她拍的照片）；
- 它是下一句要用的东西，提前 1 秒入场。
