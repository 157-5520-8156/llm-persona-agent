## 0. 一句话定位

**全片只讲一件事：她说的每件事，都真的发生过；而且她自己并不知道自己是 AI。**

- 语气：回形针式冷幽默——旁白一本正经，画面负责好笑。
- 结构：九段，每段一种视觉语法，快慢交替，杜绝 PPT 感。
- 时长：约 5 分 40 秒。1920×1080，30fps。

## 1. 美术圣经（全片强制遵守）

### 1.1 核心隐喻：桌上的小世界
她的世界是暖白桌面上一座**热闹的**黏土微缩校园。她在里面过得很真，我们在外面看。
> v4.0 样片的问题是“毛坯房”：只有主角物件，没有环境。v4.1 起，**每一帧都必须有三层景深**：前景道具（虚）、主角（实）、远景校园（虚）。

### 1.2 唯一语义规则：**真 = 实心；编 = 线框**
| 状态 | 视觉 |
|---|---|
| 真实发生、有来源 | 哑光黏土实体，有阴影；可连**糖包橘**来源线（来源线会发光） |
| 现编／视锥外／不存在 | 灰色线框 `#9A9A9A`，轻微闪烁，无阴影，无颜色 |
| 她的主观感受 | 实体 + 内部柔光（橘色 emissive 0.15–0.2） |

### 1.2.1 记录的视觉语言：小票机（v4.2）
- 观众不懂“结算”“账本”“事件”。全片统一用一个日常物件表达“系统记下了一件事”：**桌角的黏土小票机（奶油黄，正面标签“她的世界”）**。
- 世界里发生一件事 → 小票机指示灯变橘、机身轻震、“咔哒咔哒”吐出一张热敏小票（锯齿底边、等宽字体、橘色大号时间、地点、两三行大白话、底部条码；只有真实记录才印事件序号，例如 `No. 087682`）。
- 来源线的标准链路：**她的话 → 小票（记录）→ 发生的地方（黏土场景）**。禁止再出现“悬空的时间戳卡片”。
- 小票上只写大白话：`08:45 / 华师大 · 食堂早餐窗口 / 肉包……售罄 / 买到：糖包×1`。全片禁用“结算、事件、账本、投影”等内部词。
- 第一次出现时旁白交代一句：「她的世界每发生一件事，都会吐出一张小票。」之后各段直接复用，不再解释。
- 小票可以“翻面”：翻过来就是 Dashboard 实录画中画（见 2.9）。这是全片唯一的“动画 → 真实系统”切换手势。

### 1.3 色板
**主色（语义）**
| Token | 值 | 用途 |
|---|---|---|
| `paper` | `#F2EEE6` | 背景／桌面 |
| `ink` | `#1C1C1E` | 文字 |
| `chip` | `#FBF7F0` | 她的话（词块、气泡） |
| `card` | `#FBF8F2` | 时间戳卡片 |
| `orange` | `#FF6A2B` | **只用于**来源线、关键词、真实性强调 |
| `ghost` | `#9A9A9A` | 线框／虚假 |
| `qq` | `#4B9BF5` | 用户（你）发的气泡 |

**次级色（布景专用，绝不承载语义）**：鼠尾草绿 `#A9BC9C`／深绿 `#8FA584`／雾蓝 `#A9C6DA`／奶油黄 `#F2D58C`／腮红粉 `#EDBFAF`／薰衣草 `#C9BEDD`／木色 `#B98F6A`／石板灰 `#6E7480`。
建筑、树、道具用次级色，饱和度保持低；同一画面次级色不超过 4 种。

**禁止**：深蓝底、霓虹描边、金属、紫色渐变。

### 1.4 质感
- 所有黏土：`roughness 0.85–0.9`，加**指纹噪声 bump**（已实现 `clayBump()`），让表面有手捏的颗粒。
- 玻璃：`meshPhysicalMaterial`，clearcoat 1，透明度 0.2，墨色细边框。
- 发光物（来源线、路灯、浮尘）：颜色乘 1.3–1.6 且 `toneMapped=false`，只有它们会进入 Bloom。

### 1.5 光与后期（已实现，全片沿用）
- 主光：左上暖光 `#FFF4E6` 2.0，软阴影（shadow radius 8）。
- 补光：右侧冷光 `#CFE0F0` 0.55；背光 `#FFE9D2` 0.7 勾轮廓。
- 后期链：N8AO 环境光遮蔽（暖棕色 AO）→ **景深（焦点跟着主角走，前后景虚化，微缩感的关键）** → Bloom（阈值 1.0，只亮发光物）→ 胶片颗粒 4.5% → 暗角。
- 光里飘浮尘（`DustMotes`），让空气“有东西”。
- **母题：影子转动 = 时间流逝**（第 3 段用）。

### 1.6 字体
- 标题：宋体 Heavy（`Songti SC` 900）。一屏 ≤ 12 字。
- 正文／字幕：`PingFang SC` Medium，40px，带半透明纸色底。
- 时间戳、数字：`SF Mono`／JetBrains Mono。

### 1.7 运动法则
1. **一切从世界来，回到世界去**：物件从桌面下升起或从上方落下，弹簧落定（damping 12, stiffness 120, mass 0.8）；退场沉入桌面或折叠，**不淡出**。
2. 任何时刻只有一个主角在大动；布景只做“呼吸”级微动（浮尘、热气、树叶 ±1%）。
3. 镜头永远在缓慢运动；笑点前一拍镜头停。
4. **焦点也是运镜**：每次主角切换都做一次 0.6s 拉焦。
5. 段间用“物件转场”：上一段最后的物件变成下一段的第一个物件。

### 1.8 声音
- 旁白：见第 5 节语音清单。
- 音效：黏土落桌“嗒”、纸张、线生长的细微“嘶”、玻璃碎裂、闹钟铃。
- 母题：钟表滴答贯穿全片；笑点处整轨静音 0.5s。
- 配乐：极简钢琴 + 轻电子底；第 4 段抒情起，第 6 段卡点。

### 1.9 合规小字
片尾 + 第一次出现对话时右下角 3 秒：
`部分对话为根据真实运行记录的情景还原；角色与校园为虚构，照片与声音为生成内容。`

## 2. 分段剧本

> 格式：**旁白**／**画面**／**运镜**／**动效**／**素材**。旁白编号与第 5 节语音文件一一对应。

### 段 0 · 冷开场「这也太假了」（0:00–0:18）
- **画面**：纯黑 → QQ 私聊（手机竖屏居中，暖白背景，手机周围散落几件黏土小道具：一杯豆浆、一本书、一盆小绿植，景深虚化）。你发出一张 B 站视频卡片（某个公开的 AI 女友演示）。她的回复逐条弹出（**占位，以实录为准**）：「这也太假了吧」「谁会这么说话啊」。
- **旁白**：无，只有钟表滴答。
- **运镜**：手机从下方 10% 上推至居中（3s），最后一条消息出现后镜头停。
- **动效**：最后一条落定 → 静音 0.5s → 硬切黑场 → 宋体「浮生引擎」逐字落下（每字 3 帧，回弹），下方小字 `CONTINUUM`。
- **素材**：把某个 AI 伴侣视频发给知栀，录屏真实反应。

### 段 1 · 视锥剔除（0:18–1:05）
- **旁白** N1-1 … N1-7：
  1. 「先做个小实验。打开任何一个 AI 伴侣，问她：早饭吃了什么？」
  2. 「她会回答。很自然，很可爱。」
  3. 「但在你问之前，这份早饭并不存在。」
  4. 「你一转头——它又没了。」
  5. 「游戏行业管这个叫：视锥剔除。镜头看不到的地方，就不渲染。」
  6. 「这很省钱。这也是今天几乎所有 AI 伴侣的世界。」
  7. 「我们想做一个，镜头外也在渲染的世界。」
- **画面**：
  - 俯视 35° 整座微缩校园，**全部灰色线框**，薄雾。
  - 一只黏土手机悬在左上，屏幕射出半透明光锥（手电筒）。
  - 句 1–2：光锥扫向食堂，被照到的部分线框→实体“长出来”（自下而上体素化 0.6s），弹出甜腻气泡「今天吃了小笼包哦～」（线框字）。
  - 句 4：光锥移开，食堂从上往下碎成线框灰尘塌回去，配“噗”。
  - 句 5：左侧滑入宋体大字卡 `视锥剔除 / Frustum Culling`，小字「看不到的，就不算」。
  - 句 6：拉远，全城线框，只有光锥里一小块实心。
  - 句 7：“嗒”——全城从中心向外一圈圈变成彩色实体（波纹扩散 1.5s，次级色依次上色），路灯亮，小人开始走，影子出现，浮尘出现。**这是全片第一次“满色”，要给观众“哇”的一下。**
- **运镜**：句 1–4 跟光锥平移；句 6 crane up + 拉远（FOV 35→45）；句 7 orbit 20°，焦点从中心向外拉。

### 段 4 · 一生（2:45–3:40）（并入美化场景 ③）
- **旁白** N4-1 … N4-8：

4. 停 1.5–2s，缩回，触发物归位，世界继续。
5. 全片 PiP **合计不超过 12 秒**，每次只高亮一处；再多就会退化成 v3 式“看板堆砌”。

## 3. 技术实现说明

### 3.1 工程
```
output/bilibili-launch-v4/
  remotion.config.ts      # Chromium GL = angle（mac 下 WebGL 渲染必需）
  src/theme.ts            # 主色 C、次级色 P、弹簧参数
  src/lib/util.ts         # 种子随机、ramp、关键帧相机 sampleKeys
  src/lib/textTexture.ts  # 3D 内中文 → CanvasTexture
  src/three/parts.tsx     # WordChip / GhostChip / SourceWire / StampCard / ClayCanteen / GlassGate
  src/three/props.tsx     # ClayMat(指纹噪声) / ClayTree / ClayLamp / ClayBuilding / SoyCup / Steam / DustMotes / ClayClock / AskBubble
  src/scenes/S2Explode.tsx# 段 2（样片），含相机 KEYS、焦点 FOCUS、后期 Post
```
- 预览 `npm run studio`；样片 `npm run render:sample`。
- 硬约束：动画只能由 `useCurrentFrame()` 驱动；随机只用 `seeded()`；3D 中文只用 CanvasTexture；2D 字幕/标题用 DOM 叠层。
- 已踩过的坑（必须遵守）：
  - `RoundedBox` 的 `radius` 必须**小于最薄边的一半**，否则生成退化法线，配合 bump + Bloom 会让整帧变黑。
  - 物件出场/退场用 `visible` 或 `scale` 控制，**不要条件卸载网格**。
  - 每个 Composition 的 `Post` 必须带首帧预热和逐帧补渲（照抄 `S2Explode.tsx` 的 `Post`），`ThreeCanvas` 需 `preserveDrawingBuffer: true`。
  - 渲染后用 `npx remotion ffmpeg` 抽帧检查有无黑帧（亮度均值 < 150 即异常）。
- 新段落：复制 `S2Explode.tsx` 的骨架（Rig + World + Post + DOM 叠层），在 `Root.tsx` 注册为独立 Composition；全片最后用一个 `Full` Composition 以 `<Series>` 串起各段并挂旁白音轨。

## 4. 给动效 AI 的提示词

> 用法：先把 **4.0 总提示词**和本文件一起发给负责写代码的 AI，然后每次只发一段的分段提示词。每段做完先渲 6 张静帧拼图自查，再渲视频。

### 4.0 总提示词（每次对话开头都贴）
```text
你在 output/bilibili-launch-v4/ 这个 Remotion + React Three Fiber 工程里，为一部 B 站产品发布会制作 3D 动效段落。
请先完整阅读 docs/design/bilibili-launch-2026-11-05/script-v4.md（下称剧本），以及 src/scenes/S2Explode.tsx（已完成的标杆段落）。

风格硬规则（违背任何一条都算失败）：
1. 世界是暖白桌面上的黏土微缩校园。所有物件用 src/three/props.tsx 的 ClayMat（带指纹噪声），哑光，圆角，像手捏的。
2. 语义：真实发生的东西 = 实心黏土；编造/不存在的 = 灰色线框(#9A9A9A)、闪烁、无阴影。橘色 #FF6A2B 只给“来源线/关键词/真实性”，布景永远不许用橘色。
3. 布景用次级色板 P（鼠尾草绿、雾蓝、奶油黄、腮红粉、薰衣草），同屏 ≤4 种，低饱和。禁止深蓝底、霓虹、金属、紫渐变。
4. 每一帧必须有三层景深：前景道具（虚）、主角（实）、远景校园（虚）。不许出现“只有主角飘在空白里”的毛坯画面。
5. 后期沿用 S2Explode 的 Post：N8AO + DepthOfField(焦点跟主角) + Bloom(阈值1.0，只亮发光物) + Noise + Vignette。
6. 运动：物件从桌面升起或从上方落下，弹簧 {damping:12, stiffness:120, mass:0.8} 落定回弹；退场沉入桌面，绝不淡出。同一时刻只有一个主角在大动，布景只呼吸级微动（浮尘、热气）。
```
