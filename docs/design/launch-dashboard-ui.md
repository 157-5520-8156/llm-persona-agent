# 发布面板：生活视图与录制模式

本片基于 `7a37c2a1`，只改变认证 owner 页面的呈现。遵守 ADR-0010 的角色决定权与
ADR-0018 的独立只读投影：浏览器仍只轮询同源 `/world-v2/dashboard/home`，沿用
`world-v2-dashboard-home.1`、session、ETag 和 15 秒轮询。不新增模型、World 写入、检索或
数据源。未部署，不代表真实 provider、长期生活连续性或公开视频资格通过。

页面默认展示“这一刻”、活动与计划、最近的生活记录、记忆、情绪、关系和未完成事项。运维与其他记录
折叠。小屋 iframe、编辑及独立页面链接从默认面板移除，原独立静态路由和 room route 转换接口保留；
浏览器不根据位置或活动推导房间移动。

## 呈现边界

- 当前状态、标题、正文和状态标签只取服务端授权的 `DashboardEntitySummary`。
  原已选意图的 `intention` 完整值在活动卡片显示；计划窗口只作为所选时间，不充当发生时间。
- 生活记录按 `occurred_at` 排列，保留每个节点自己的类型和状态。无连接线、因果箭头或本地
  ref 关联。它是有界的当前摘要，不是完整事件历史；缺少条目不表示事件不存在。
- Plan 不等于正在执行，活动结束不等于目标达成。环境结算状态不证明角色回应，Experience
  来源状态不等于已安装环境/回应全文 reader。本片不拼接这些正文。
- 记忆候选和已确认事实分开命名；情绪只展示已记录摘要，不声称当前完整内心独白。
  `PrivateImpression` 不进入正文，只有服务端计数；`withhold` 行不进入任何显示卡片。
- 未完成事项并列呈现原 thread / commitment / interaction bid 以及 revisit / response
  expectation 摘要，保留开放、已完成、已过期等原状态，不按当前时间或正文另判仍在等待。
  两组来源分别表达不可用，某组缺失不会抹掉另一组已取得的记录。
- 不渲染任意 payload 树或原始 world/owner/ref/hash/prompt。所有动态文本使用 `textContent`。
  录制模式也不改变源数据的隐私资格；选择分享哪些已授权摘要仍由录制者负责。
- empty、unavailable、首次读取失败和旧快照不同。失败后保留最后一次成功快照并明确标旧；
  304 可以恢复“已同步”。请求互斥，慢请求不会并发累积。

## 录制操作

点击“录制模式”后文字放大，可选择完整视图或聚焦这一刻、生活进展、记忆、情绪、关系、未完成事项。
运维与登录退出控制隐藏；同步状态、陈旧提示与私密内容范围说明始终保留。
退出按钮或 Esc 恢复完整视图和进入前的滚动位置。此操作不提交数据、不暂停世界、不更改
轮询、账本、角色选择或浏览器持久存储。

## 本机离线布局预览

在本分支根目录执行（不要从另一个 checkout 导入 editable 包）：

```sh
PYTHONPATH=src COMPANION_DISABLE_DEBUG_USAGE_LEDGER=1 \
/Users/geoff/Projects/Girl-Agent/.venv/bin/python \
tests/world_v2/test_dashboard_life_preview.py --preview --port 18941 --state normal
```

打开 `http://127.0.0.1:18941/dashboard`。使用 Ctrl-C 关闭。该入口只监听 loopback，只有
固定 HTML、JS 和手工 DTO；不加载凭据、不打开 SQLite、不调用模型/QQ/实际 owner。页面持续
标记“离线布局样例，不是真实角色记录”。**它没有实际 owner 登录能力，也不能用于代理
实际数据。**

`--state` 支持：

| 状态 | 预览行为 |
| --- | --- |
| `normal` | 手工样例活动、未来计划、经历状态、记忆与情绪 |
| `empty` | 独立空内存 World 编译出的真实空 DTO，没有编排领域事件 |
| `failure` | home 接口持续 503，页面显示不可用，不补零 |
| `stale` | 首次返回样例，下一次 15 秒轮询开始 503，保留旧数据并标旧 |

更换状态请关闭并重启，或指定不同空闲端口。样例之间只有排列关系，没有编造确定因果。
实际脱敏 owner 数据的浏览器验证由单独的只读 source 入口进行，不与手工布局样例混用。

## 验证范围

既有 Python HTTP 测试验证认证、同源、ETag、loopback、错误脱敏和独立小屋路由保留。
Node 测试运行实际客户端纯函数与带最小 DOM 适配的完整脚本，验证录制聚焦/恢复、轮询失败、
304 恢复、原数据不变、无额外写请求、隐私 canary 与 `textContent` 安全。
DOM 适配不是浏览器布局测试。桌面/窄屏布局与真实数据密度须另作浏览器视觉验收，不能以这些
机械测试冒充截图或真人感资格。

## 2026-11-01：按阅读目的组织的青绿看板

当前页面将默认入口改为生活总览，另设生活日程、故事脉络、关系与记忆、照片与见闻、运行观察。
样式集中在 `dashboard_presentation.py`；原 owner 数据来源与授权边界保持不变。

- 总览以活动与计划为主要内容，情绪、关系和互动状态紧凑排列；环境与原意图按需展开。
  已结束事项收进历史折叠区，详细计数与费用在运行观察中查看。
- 日程保留周／页／类型／状态筛选，七个日期按钮只展示当前页的数量；选中日期以时间线和详情显示。
  不再在首次渲染前逐页拼接全周快照；本页缺少记录不等于当天没有记录。历史仍可翻页访问。
- 故事结构按章节、故事线、进展与关联候选分层。默认选择一条线，候选可展开；
  节点点击与键盘操作读取原摘要，不将展望解释为已发生事实。
- 相册使用无重叠网格、照片放大和键盘退出。历史摘要中的序列化对象不当成照片说明显示。
  关系雷达要求六项数值齐全，否则显示实际已有字段；情绪与身体条形图只使用提供的百分比。
- 保留分区、选中日期、展开状态与录制前视图；光晕、悬停和机制连线动画遵循 reduced-motion。

验证：dashboard HTTP／客户端／日程／覆盖检查共 62 项 Python 测试通过，客户端桥接中包含
48 项 Node 测试。使用现有 owner 的授权数据完成 390、768、1280 像素下六个分区的浏览器边界检查，
照片无交叠；另检查离线 empty、failure 显示和照片预览 Esc／焦点恢复。
这仅证明本次界面与机械契约，不增加模型、QQ 交付或长期角色质量的资格结论。
本次未重启运行中的 QQ owner；工作目录的新版需要宿主下次加载代码后用于原服务入口。
