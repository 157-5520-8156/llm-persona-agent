# World consequence evidence content

The closed `release-chat-life-context-20260915-01` trial exposed a source
catalog error: execution IDs, revisions, hashes, `epistemic_scope` and
`truncated` were selectable as evidence of an external action. A reviewer
selected these alongside an in-progress walk result to support a return.
Neither the metadata nor that body established a return. The subsequent
technical failure does not erase the semantic false support.

## Boundary and version

Independent review version 13 (`visible-independent-review.5`) retains the
existing v12 two-reader, subjective-history and shared-string pipeline. For
verified settled-life source rows it exposes only
`world_consequence.environment.text` and
`world_consequence.authorized_attempt_result.text` as direct readings.
Original material, times, execution binding and provenance stay intact for
scope checking. Environment remains nonpersonal; an authorized attempt's
body is limited to its owner. The model still judges what the body entails.
Restricting this catalog cannot by itself prevent semantic false support.

The reading compiler owns field selection; receipt composition binds that
selection to a new protocol. Historical v9–v12 compilation is unchanged, and
deployment defaults are unchanged. Protocol 13 preserves pinned subjective
sources and the v10 complete-meaning reader. No extra provider call, author
retry, behavioral rule, delivery authority or automatic silence is added.

## Failure visibility and verification

Technical review diagnostics now identify meaning preparation/read, source
preparation/read, receipt or evidence assembly. Arbitrary exception text is
not copied into the audit. Technical failure cannot open semantic author
reselection. This instrumentation does not yet diagnose the historical
ValueError; a phase observed in a later run is not proof of an earlier cause.

Tests cover native environment ownership, unchanged source material,
catalog substitution, subjective-history scope, public inbound/proactive
v13 review, semantic reselection, cold replay and post-review technical
failure. Real provider delivery and semantic qualification remain separate.
