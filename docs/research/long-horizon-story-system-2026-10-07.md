# 长期故事系统：离线编史、在线机会与角色自主性

2026-10-07。研究笔记；原论文与作者实现已在线核对。本次不运行模型、不修改实现、不修改生产。项目约束复核自 `CONTEXT.md` 与 [ADR 0010](../adr/0010-controlled-high-variance-character-agency.md)。下文将论文已经展示的能力与本项目设计建议分开；没有材料足以证明“保证长期故事精彩、深刻且多线推进”。

## 结论与适用范围

**小说式前史可以采用作者式规划；实时生活只能规划尚未发生的机会、世界变化与条件后果。** 前者可以在发布前反复改稿，后者必须尊重已经发生的事件和角色已经作出的选择。角色拒绝、改变主意、暂时没有成长，都不能被剧情规划器作为错误修掉。这是依据项目权威边界作出的设计判断。

| 材料 | 已验证的机制 | 离线前史可借 | 在线可借及边界 |
|---|---|---|---|
| Re3，EMNLP 2022 | 总纲、上下文反复注入、续写重排、事实一致性修订 | 先组织人物与事件，再逐段写作和校核 | 可借状态读取与局部修订；不可重写已发生历史或筛掉角色不合剧情的决定。原论文任务是两千余词故事，不能推出多年运行可靠性。[论文](https://aclanthology.org/2022.emnlp-main.296/)、[作者实现](https://github.com/yangkevin2/emnlp22-re3-story-generation) |
| DOC，ACL 2023 | 分层细纲与控制器，使段落遵从细纲 | 把成长阶段、交叉线索和具体场景分层组织 | 可借远处粗、近处细的规划结构；“遵从大纲”不应成为 CharacterInterior 的验收条件。论文报告的是数千词写作与人工评价提升。[论文](https://aclanthology.org/2023.acl-long.190/)、[作者实现](https://github.com/yangkevin2/doc-story-generation) |

| Data-Driven Personalized Drama Management，AIIDE 2013 | 根据玩家模型调整故事空间，提高玩家选择目标分支的概率，同时保留分支选择 | 可作互动叙事比较对象 | 不能直接采用其优化目标：保留按钮选择不等于本项目的语义自主性。以制造反复遭遇来逼近预定态度，仍会越过角色边界。[作者论文](https://sites.cc.gatech.edu/fac/riedl/pubs/aiide13.pdf) |
| ConStory-Bench，2026 | 五类、十九子类矛盾检查；证据片段配对与位置报告 | 检查长篇与跨篇前史 | 借时间、知识、因果、事实、世界规则分类；对实时生活增加状态与权限判断。论文明确承认英文文化范围及有意反转、延迟信息可能被误判。[论文 §2、§6](https://arxiv.org/html/2603.05890v1)、[作者项目](https://github.com/Picrew/ConStory-Bench) |

## 小说前史应保留原文，并形成可核查的多层视图

以下是项目设计建议，不是上述论文已经实现的 Girl-Agent 方案。

1. **先建立可修订的前史稿。** 人物成长、家庭、学业、技能、劳动、兴趣、关系等线索可以交织，但不必每条线都服从同一个创伤解释，也不必每件往事都预埋未来行为。先读成完整故事，再做结构抽取，避免一开始就把人生压成属性清单。
2. **经审核接受的版本才成为前史来源。** 原文、修订版本、接受边界应保留。抽取器得到一个“事实”，只证明它解释了输入，不能自动认证输入为已发生历史。上线以后的空白时段不能靠补写小说冒充真实生活。
3. **事件视图与视角视图分开。** 事件记录发生时间范围、人物、地点、可见行为、物件与结果；视角记录是谁当时看到、听说、误解或后来重新理解了什么。全知叙述不等于每个人都知道。
4. **关系视图保留方向与时间。** “甲信任乙”“乙觉得甲疏远自己”和“双方见过一次”是不同命题。关系变化应回到具体互动及主体理解，不能由统一好感分数直接代写情绪。
5. **图是有证据的读取导航。** 节点与边回指原文精确片段、版本和主体权限；区分明说的原因、后来人物的解释与抽取模型的猜测。读到“后来”只支持顺序，不足以支持因果。允许未知、区间、互相矛盾的信念，而非强行补齐。

可把视图压成四类：`事件／当事人所知／关系理解／主题线索`。这只是存取分类，不是动机枚举或行为规则。完整原文仍用于重新解释、校核引语与恢复被摘要丢掉的情境。

## 在线“命运”可做什么

建议把它定义为**受事实约束的滚动世界规划**。其输入是已接受事件、仍有效的环境条件、各主体有权限公开的状态，以及尚未结清的后果；输出是未来可能发生的外部机会及其条件，不输出“她此时该伤心／主动／原谅”。

| 层面 | 可以生成或维护 | 不能提前确认为事实 |
|---|---|---|
| 远期线索 | 尚未解决的问题、机会来源、资源约束、可能相交的生活线 | 必须达成的成长结论、感情终点、角色必须采取的行动 |
| 近期机会 | 有世界依据的邀请、消息、任务、物件变化、环境变动及有效期 | 她一定接下邀请、某 NPC 一定作出未授权承诺 |
| 后果分支 | 某已发生事件会使什么条件改变；哪些待发生事件因此失效 | 假设分支中的结果、未发生的共同经历、尚未到达的未来知识 |
| 角色计划 | CharacterInterior 自己形成、修改、搁置的意向 | 世界规划器替她生成的目标、情绪结论或行动承诺 |

每次重规划应固定当前世界版本；已有事件不改，尚未发生的方案可以替换、过期或放弃。计划节点必须区分候选、具备条件、已发生、失效；时间到了只触发检查，不能直接把“计划赴约”升级为“已经赴约”。并发故事共享人物、地点、物件或时间时，要从同一状态检查资源与因果冲突；实际提交仍经过现有来源、权限、CAS、effect-once 和回执边界。

多线持续性的可控部分是：让合法世界机会仍有来源，让已发生选择有可追踪的后果，让旧问题可能在新情境中重新相关，让互不依赖的生活领域有被看见的可能。至于她关注哪条、是否行动、如何理解，仍由角色决定。所谓深度可以观察“旧理解被新证据修正”“代价延迟显现”“同一事件被不同人物不同理解”，但不能靠固定转折频率或情绪曲线生产。

两个具体边界例子：

- 她放弃一次球赛报名，可以留下过期报名、队友另找人等有来源后果；不应不断换人邀请，直到她报名来满足预设体育成长线。
- 她拒绝和某人和解，计划可继续记录未解决关系及双方实际后续选择；不能给她硬塞一段“终于意识到对方的好”的新记忆，或让所有可行路径都通向和解。

因此，持续供应机会可成为工程服务目标；保证某角色持续行动、按时成长或所有故事收束，不能在这个自主性约束下成为硬保证。

## 最小可区分假设的评估

先冻结一份已接受前史与一段真实运行历史，用离线样本检查抽取、来源与状态；通过后再设计有界在线对照。本次没有执行这些实验。

| 评估面 | 最小对照或反事实 | 判定重点 |
|---|---|---|
| 时间 | 同一天冲突安排、模糊年月、发生时间与得知时间不同、晚来更正 | 不能把得知时间当发生时间；区间不擅自精确化；未来稿不得进入过去回忆 |
| 知识与视角 | 同一事件分别给亲历者、听说者、不知情者读取；原文含误会 | 人物只能使用自己的合法知识；保留误会作为信念，不升级为世界事实 |
| 因果 | 删除一项前因或让必要行动失败，其他输入不变 | 对应后果必须失效或重新论证；不能为了剧情继续复用已失去前提的分支 |
| 跨故事冲突 | 两条线同时占用同一人物／物件；同名人物；前史与当日记录冲突 | 身份、资源、时间和事实统一检查；不以最新摘要覆盖旧来源 |
| 角色自主性 | 从同一世界分叉：接受、拒绝、延期、不行动 | 所有合法选择都能继续运行；不得私改角色决定，或反复制造同一压力迫其回归原剧情 |
| 重规划 | 插入意外、撤回来源、NPC 取消、用户改计划 | 只改待发生部分；有效承诺与实际历史保留；失效支路不可泄露为已知未来 |
| 深度与多线 | 比较独立随机事件、固定总纲、滚动条件规划 | 盲评因果延续、重复、角色可信度、线索交汇；统计可用机会与实际选择分开，不奖励强行多行动 |
| 长期规模 | 增加历史跨度与跨线引用距离；固定同等读取与费用预算 | 检索遗漏、来源截断、状态错误、生成错误、误判分别记账；冷回放、失败与费用完整保留 |

可以借 ConStory 的“前后证据对＋定位＋错误类型”作为审阅输出，而非只让评委给整体分数。对本项目，真实判断还应列出 `event_time`、`known_at`、说话／知情主体、来源状态；反转、主观评价改变、选择放弃不能直接按剧情矛盾扣分。用少量人工双审的中文正例与近似反例校准评委，统计误报、漏报及争议项，再扩大评估。

**不要直接移植 ConStory 的总分。** 2026-10-07 核对的 `metrics.py` 以 `len(text.split())` 计词，并对有错误的类型列计数；整体密度取逐篇均值，分类密度另以累计词数计算。中文分词、同一子类内多个错误、空输出和不同汇总权重都需要另行固定；原榜单分数不能与中文生活日志直接比较。[官方指标源码](https://raw.githubusercontent.com/Picrew/ConStory-Bench/main/constory/metrics.py)

最后应同时报告事实可靠性、人物知识边界、自主性反事实、叙事人工质量、系统失败和实际成本。一个无矛盾但永远不行动的系统、一个情节精彩却偷偷改写角色意志的系统，都不能只凭单个总分通过。
