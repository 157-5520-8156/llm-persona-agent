# 世界后果与角色生活回应分别拥有作者

World Author 只拥有环境机会与客观后果的创作权；随机结算不能给角色新增行动、意图或
内心。角色如何理解事件及随后要做什么，由已有的 CharacterInterior 世界感知回合
自行创作。环境结算、角色回应、未来行动意图与实际执行各自保留来源，不再将选择一段
World Author 正文解释为角色创作了这段生活。

当前冰雹反例已通过公共 SQLite 链确认：只有 Clock 的世界可以随机结算“她及时收回
手账”，继而将其写入经历和回忆；全程没有角色行动决定。ADR-0012 中允许候选预写角色
动作、感受和主观回应的旧表述，在作者权限上由本 ADR 及 ADR-0010 取代。历史已提交
事件仍保留原字节和原权限解释，不能补造新的角色作者证明。

## 取舍

复用已有 `world_stimulus → CharacterInterior.experience` 回合承载回应，并开放已存在
的自定活动意图能力。意图通过独立的世界事件来源进入 Plan 和活动生命周期；不能伪装
成入站消息，也不能凭意图写成已完成行动。这样可让角色真的安排后续事情，同时避免
为每次世界事件再增加一个角色审核回合。记忆保留仍在经历提交之后，不倒写自己的来源。

直接给 outcome selection 增加一句回应，仍会把世界作者预写的结果正文当作角色事实；
只改 Experience 摘要则会遗漏 occurrence result 的聊天和 Recall 入口。这两种局部
替换不足以完成迁移。新的世界后果和角色回应必须分别绑定作者，接受端和读取端共同
识别权限。新自然语言合同仍可能有语义违规，必须继续用真实模型反例验收。

## 实施状态

本 ADR 确定目标 Interface，未声称完整实现。迁移按
`docs/design/world-consequence-role-response-implementation.md` 推进；任何一片局部检查
通过都不能关闭现有 World Author 正文越权问题。已授权行动的后果若需要新的世界创作，
作者必须看到实际执行来源；不能用事后补 Plan ref 为预写动作补授权，调用成本也不能
一概宣称不增加。
