# 可修订的世界前瞻（命运层）

用户于2026-10-08批准实现，10-09进一步明确成本边界：只有主角独立思考；NPC与外部事件由统一世界作者预写，执行时不再各自调用模型。基线9cb07f2b。复用ADR0010/0019和LifeEcology调度，不新增独立循环。

## 权威与执行

前瞻是世界作者的私有草案，不是事实、主角计划或记忆。以长期事项、共享节点、时间窗口、来源和状态条件组成可修订图。中央模型共同编排NPC和外部世界，保留NPC身份、隐私、状态及已有历史；不要求每个NPC拥有一次单独的思考。主角的动机、回应、参与和选择继续属于CharacterInterior。

第一版执行包限定为外部环境事件和有明确说话者的NPC原话。NPC说法只证明他说过，不认证说法内容为真。不支持凭脚本替主角发送消息、承诺参与、移动或修改内心。文本语义仍依赖中央作者遵守权限；结构校验不能证明任意自然语言完全不越权，真实模型质量验证尚未完成，不据此开启生产。

未来草案不进入角色Context和Memory。独立sidecar保存版本、请求、模型结果、技术失败、投放和回执；当前节点执行才通过OccurrenceContentCoordinator及原Occurrence生命周期成为当前来源，保留中央作者的请求/响应摘要和原操作定位。脚本执行不伪造一次新的ModelResult。

## 成本与变化

显式开启中央模式后，关闭旧NPC独立决策入口；普通事件不再在执行时调用World Author。主角的实际行为结果仍走已有世界结果结算流程，需要语义解释的新情况由同一个中央作者处理。这里的“零调用”仅指预写脚本投放，不包括主角感知、选择、后果结算和记忆处理。

前瞻刷新由原有LifeEcology有界后台机会驱动，复用同一预算作用域；不在用户回复热路径重写未来。正常脚本投放和其Occurrence进展不单独触发重写；状态/来源变化、条件失效、取消、过期或作者选定复查时间会使草案待更新。无新增独立语义审核器；非法结构由同一作者最多修正一次，仍失败记技术失败。

条件只检查明确实体状态/版本，不用关键词、情绪阈值或代码替主角选行为。来源变化只废弃相应条件分支；未受影响节点保持可用。前置节点必须实际产生仍有效的事件，不能用候选、失败或取消充数。图的先后顺序不构成语义因果证据。

显式配置WORLD_V2_LIFE_OUTLOOK_ENABLED，默认关闭，隔离测试开启。本轮不动真实QQ、生产进程或既有实验预算。首个闭环通过并不等于长期叙事、自然对话或上线验收完成。


## 2026-10-18：多线后果与年度修订

继续扩展同一个 Outlook/Occurrence/Planning 实现，不新增剧情框架或后台循环。新鲜请求使用 `world-outlook-author-schema.8` / `world-outlook-native.6`；原已付费请求仍按其固定消息、工具契约和旧校验版本恢复。

- 年度阶段关联故事线与既有来源状态条件；至少两条持续生活线各自给出不同可能发展。发展是私有假设，不能授权角色的选择或预写她的感受。
- 角色实际行动的 World 后果仍由原作者、来源审核、权限审核和结算接受。需要延续的客观资源／义务等使用原 `objective_biographical_transition` 坐标保存；失败或拒绝不要求产生新坐标。主观计划和人生方向仍属角色。
- 新终态、事实变化、阶段条件失效和物质后果唤醒原准备通道，复用失败回执、小时退避、CAS 和重放。普通自产脚本的正常进度继续去重，实质客观转变不能被当作普通进度略过。
- 新稿须逐项说明已接受变化的修订／保留决定。声明修订必须关联该来源并改变未来的有效结构；只有理由、来源条件、关联字段或同一事件的重措辞不算结构变化。规划键的替代还须指向当前准确前驱并立即开放发表窗口。结构校验不能证明任意自然语言的语义因果；真实对照需另核对具体状态和安排。
- 独立未受影响线保持原样；已发生的历史不改写。机会及年度阶段复用同一来源条件检查。沿用既有年度覆盖／七日复核与近期详细日程续编。
- 变化读取复用原精确结算内容读取器，检查内容类型、契约、哈希及补偿性权限限制，嵌套 `withhold` 转变不进入作者提示。滚动扫描每批推进一项变化；完整内容留在不可变存储。展示摘录有明确截断标记和源哈希，实际剩余字节不足时再收敛变化展示；最少保留 512 字符的可读材料，否则保留待处理来源并记录原 100 KB 入参失败，不能用空证据推进游标。展示哈希与完整来源哈希分别命名。

本扩展不自行部署到 QQ。隔离真实 GLM 对照使用相同起点和受控、已接受的角色行动干预；World 作者与审核为真实调用。该实验检验世界后果闭环，不代表角色自主选择质量、长期自然叙事或生产陪伴效果已获证明。
