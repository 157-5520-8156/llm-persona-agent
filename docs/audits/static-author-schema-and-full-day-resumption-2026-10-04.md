## 保留可证实的本地优化

World Author 工具的静态 schema 原来每次都重新执行 Pydantic schema 生成、内联和完整 $def factoring。缓存只按五个已知 contract_id 保存静态模板；每次返回深拷贝，并重新读取供应商的实时 forced/auto 模式。没有缓存 World、来源、角色选择、审核结论或授权。

同一进程十二次冷/热测量：构建中位数约 41.25ms → 0.35ms。五种协议与改动前保存的工具对象逐值相等。专项测试验证缓存返回值被修改不污染后续请求、供应商模式切换即时生效、非法模式仍拒绝，旧工具哈希、真实适配器离线 HTTP、来源审计与恢复重放一并覆盖，74 项通过。Ruff 和 diff 检查通过。

这约 41ms 是生活作者工具构建的本地节省，不能称为聊天整链路节省或 API 费用下降。证据在 `output/private-audits/static-world-tool-20261004/`。
