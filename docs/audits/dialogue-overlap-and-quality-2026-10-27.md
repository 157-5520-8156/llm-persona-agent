# 2026-10-27 对话时间、并发与自然度调查

## 观察边界

本次以东八区 00:09–00:18 的 QQ 真实入站、原始作者输入、接受记录及平台回执为证据；
未送达的模型草稿不当作用户看到的回复。角色连续解释、重复转述、替对方补充心理状态是
实际交付中的观察，不等于已识别某条提示词或某个模型的唯一因果原因。

00:18:22 的用户消息在本机 ingress 有精确接收时间；上一轮四条消息的平台 ACK 发生在
同秒及其后三秒内。模型后续请求把四条角色话语放入 stable_turns，再把当轮用户消息放入
volatile_last_turn。展示顺序不能证明用户写消息前已经看到或回应这些话。ACK 是平台
接受/回执证据，不能证明用户阅读；单秒截断、时钟差异或缺少时区也不能推断精确先后。

`dialogue-observation-timing.1` 向新版 slim4 作者输入展示可核验的时间关系，只在对应
精度允许时区分回执记录较晚；同秒或缺失标记为不确定。保留原话、投递状态和 source
scope，且不改账本顺序。slim3 和更早的作者输入与契约不因新字段重写。

## 前台超时与并发处理

00:09:48 的失效游标期间，一条旧用户观察对应的 `FactCommittedV2` 落账；00:16:16
期间是独立生活事件的 `WorldOccurrenceSettled` 与内容落账。两次均重钉输入后耗尽
原有前台预算并记录 `primary_timeout`；模型草稿没有获得旧游标上的发布权。

事实分支现在让已在途任务在短提交处优先避让可见回合；上限到期后继续使用原有 CAS，
不能将结果写到失效快照。已返回的模型决策先持久审计；取消和冷重开后保留同一请求
hash、规范化决策及其 hash，避免无证据重复调用。此层此前未持久化 provider 原文，不能
声称其原始字节可重放。普通新增事实的 batch 准备在等待门外，物理 CAS 在门内；事实
修正、撤回及部分记忆生命周期尚未接入这条短提交路径，仍可能竞争。

世界随机事件的 aftermath 只在进入既有同步 world-contingency 段之前等待可见回合，
最长 12 秒；等待后重新核对原 wake 的身份、类型、hash、revision、时间，occurrence
实体版本和当前逻辑钟。等待期间不持有排他门，不跨模型调用持锁。记录过的随机结果、
原接受/来源/CAS 和 effect-once 保持不变。取消后原 wake 可重试，等待上限届满仍可能
竞争；独立进程、线程和未接入的后台 lane 不能靠本地门排除。原有同步 projection 会
阻塞事件循环；隔离注入 200ms 投影的测试观察到约 241ms 前台事件调度延迟，此修复并
未解决大账本启动和同步读取性能。

## 交叠入站与待发尾句

针对仅有用户输入已提交到 QQ ingress、尚未成为 Observation 的窗口，SQLite 在原
`ActionDispatchStarted` 事务内检查同一收件人的待入账片段，并排除当前 Action 所属的
精确原始 batch。对尚未开始派发且允许重新考虑的首条或后续 Beat，持久队列先行触发暂缓；
当前 Observation 随后打开原有角色重选 gate。已开始的外部请求、
回执和 effect-once 恢复不被撤销。与此无关的其他 Action 仍可继续。

due-wake 对入站暂缓会暂停本次 timer；Observation/角色选择完成后的正常宿主刷新会重建。
已打开的 reconsideration gate 不作为 timer 候选，避免等待角色时对同一个到期尾句空转。
一个独立的既有 stale-later 情况仍可能空转：角色选择继续后，旧 later 的新鲜度权威仍可
禁止发送，而缺乏单独证明的 later-refresh 定时唤醒。没有通过隐藏此类 Action 来规避。

## 冻结作者请求的对照

保留三份真实请求的完整原始作者输入和哈希，采用原 DeepSeek `deepseek-flash`、禁用
thinking、温度 0.7、最大输出 4096 的配置，仅使用 debug key；预算和调用顺序在请求前
写入私有 `output/private-audits/dialogue-choice-20261027/protocol.json`。对照 12 次：
两条倾诉上下文各比较原提示与减少先行分析措辞两次、一条日常上下文各比较一次；另外两次
仅为诊断而移除作者展示的旧 appraisal。移除 appraisal 不作为生产修复，也不改原记忆。

12 次均有 provider 返回，11 次通过旧 slim2 传输解析，1 次内部 JSON 格式错误；全部保留。
减少分析措辞或临时移除 appraisal 后，仍出现重复总结和推断对方心理。样本小且随机，
不能据此量化自然度或判定各单一因素的因果大小，也不支持发布提示词删改。

另在相同原提示、相同两个倾诉输入上请求 `deepseek-v4-pro` 四次；四次均有 provider
返回，其中一次出现否定对方感受的表述。仅作者调用耗时 6.507–8.818 秒，不包含
来源审核和提交。样本不足以判断模型总体优劣，不能据此更换生产作者模型。

对同一冻结输入添加对话时间提示后又调用四次（其中两次为真实时间重叠案例，另两次为
对照）；四次均有 provider 返回，其中一次内部 JSON 格式错误。输出仍可能出现模式化的
心理解读，因此此项只作为时序信息正确性修复，不声称提升自然度。三组共 20 次 provider
调用，回报输入 633,049、输出 5,858 token，价格和实际扣费未知；未调用图片供应商。

这些都是直接作者调用，不含独立来源审核、World 接纳、平台投递或真实多轮交互。不能以
格式可解析、HTTP 成功或单个模型评分冒充角色表现合格。人工对话评价需要结合完整的
双方回合和个体偏好；[iEval](https://aclanthology.org/2022.sigdial-1.41/) 讨论了互动
评价的局限与评价者参与对话的重要性，[多维共情系统分析](https://aclanthology.org/2024.eacl-long.11/)
也指出单一分数难以覆盖对话质量。两项论文均不能证明本项目效果，也不为角色规定安慰策略。

原始请求、模型输出、错误、用量及哈希仅保留在本机 git 忽略的私有目录，目录 0700、文件
0600；测试未向 QQ 发送消息，未修改生产数据库，也未重启运行服务。
