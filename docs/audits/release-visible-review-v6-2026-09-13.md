# Release repair: bounded whole-Beat source diagnostics

The second real input in canary 06 produced no visible reply because the v5 reviewer
returned a diagnostic sentence longer than its parser limit. The author never received
correction feedback. That closed trial remains a failure; it used nine known calls
(estimated CNY 0.1721298) and retains its entire CNY 2 allocation.

Opt-in reviewer v6 replaces free-form diagnostic prose and model-counted character
positions with a model-selected evidence-problem code and original Beat index. The
host binds that index to the complete immutable Beat. Source verdicts, selected source
authority, participant identity, disclosure, complete same-role correction and final
review remain unchanged. No local rule chooses character behavior or replacement text.
Unknown codes, bad indexes, missing/duplicate diagnostics and invalid sources fail closed.

Versions 1–5 keep their compiler bytes and historical receipt identities. V6 has a
new tool, schema and receipt identity. Default review version remains 1. V6 is available
through the explicit whole-source audit/host injection; production OneBot settings do
not yet select this complete release profile.

Acceptance is limited to targeted transport/correction/replay tests and separately
recorded real-provider canaries. Possible semantic over-rejection of conversational
acknowledgments and future intentions remains unqualified. No real QQ delivery,
production deployment, long-term personality validation or monthly cost qualification
is implied by this patch.
