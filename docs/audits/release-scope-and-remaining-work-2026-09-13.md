# 首发范围与剩余工作

2026-09-13：当前候选尚未达到邀请体验发布条件。依据最新两条真实输入及逐句来源核对，详见 [当前验收状态](release-status-2026-09-13-current.md)。

“暂不扩功能”指首发之外的独立NPC通信、新媒体能力和多人平台，不取消用户要求的生活、内心、记忆、事件后果与可录制面板。小屋与移动仍弃用。

| 用户期待 | 当前有据状态 | 剩余工作 |
| --- | --- | --- |
| 她有自己的生活，经历会影响后来 | 自主计划、环境后果、角色回应、经历/记忆已有代码链和部分真实样本；人生阶段变化有机制 | 普通聊天仍编造经历；事件丰富度与长期影响尚未充分验收 |
| 启动前也有可回忆的人生，与运行后的记忆互通 | 档案导入、角色保留、候选接受、读取/检索、聊天上下文与审核来源已接通，有离线应用链和遗忘/重启验证 | 完成正式档案与独立语义审核、压缩摘要读取；验证真实模型引用历史的正确性、完整链、跨日干扰及成本；不得补写启动后的缺失活动 |
| 人格大体稳定，记忆自然，一周内不过度重复 | 有来源绑定的状态、保留与检索机制 | 代表性的跨日/跨周真实相处证据不足，不能称完整交付 |
| 用户离开后她继续生活，回来能衔接 | 有近7小时缺席样本和后台生活记录；已接通活动完成后的自主规划机会，离线通过后仍待真实验证 | 回来后的生活追问仍出现技术超时；不能算自然沉默 |
| 发布视频能看见机制 | 面板有生活、记忆、情绪、关系、未完成事项与录制聚焦 | 最新真实生活记录的最终画面与完整复录流程未验收 |
| 每月AI成本约100元 | 有逐调用预算、费用和未知预留账本 | 需要明确每天聊天量，计入后台、审核、重试后测算；当前不保证月费 |
| 限量邀请体验 | 首发按独立World/数据库/接收人实例设计 | 候选集成、实际QQ回执、重启/持续运行、部署与回滚仍待验收；本Goal不授权这些外部动作 |

当前工作顺序：先关闭文字链事实错误与超时，再固定候选、验证三条演示与面板，随后准备邀请实例的接入和连续运行验收。代码修复与离线通过不替代真实对话验收。

本Goal新增验收项：[启动前人生档案与统一记忆](../design/character-prehistory-memory-proposal.md)。首批以已有背景和少量经检查的历史片段贯通完整链条；人生档案创作计入一次性初始化成本，运行时检索与记忆维护计入月成本。它属于首发生活与记忆主线，完成前不得称“启动前人生记忆已交付”；按需补写过去、逐日模拟二十年不在这一最小闭环内。现有事实审核误判和纠错超时仍为独立阻断。

时间判断更新：此前“可录制候选约1–2天、限量邀请体验版总计约3–5天”依赖核心聊天问题迅速收敛。正式v8复测仍错误放行无依据经历，这个前提尚未成立，因此该估计不能作为可靠交付日期。先以普通时限内完成代表性真实对话、无已知阻断性事实错误为候选冻结条件，再验收面板完整录制、实际QQ回执及重启/持续运行。长期人格、记忆与多样性的完整目标仍需后续持续迭代。
