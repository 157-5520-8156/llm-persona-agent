## 回忆的不同成本

| 阶段 | 处理什么 | 是否每次重新处理全部正文 |
|---|---|---|
| 首次准备／新增修改 | 只为缺失或变更正文生成向量，写入缓存 | 首次全量；以后增量 |
| 新查询 | 当前话题/检索线索的向量，可复用相同查询 | 否 |
| 检索 | 使用既有向量及词法、时间、显式关系，应用当前来源权限 | 当前仍逐候选本地评分 |
| 角色阅读 | 预算内选中的少量记忆片段 | 否 |

25万指的是每日累计的保守embedding预算，不是单次回忆消耗、上下文窗口或每次要读二十年。向量预算中的token数量也不能直接当DeepSeek输入量。

完整语料上三次原始查询为2.13/1.06/2.27秒；重开后为1.17/0.54/1.36秒；禁用供应商请求的已准备查询为1.00/0.40/0.95秒。样本很小、有运行环境差异，不能据此声称稳定p95或整轮聊天性能。重复查询结果hash一致，embedding缓存查询仅约0.16—0.67毫秒。
