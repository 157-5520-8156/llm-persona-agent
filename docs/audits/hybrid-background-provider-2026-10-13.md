# DeepSeek 即时交互与订阅代理后台分工

结论：混合路由已实现为显式配置；一次真实并发副本中，DeepSeek 聊天首条捕获
5.468 秒，彼时订阅代理仍在生成约58.523秒的规划。另一次串行样本的代理规划
78.430秒返回且通过合同校验。记忆整理仍失败；尚未启用生产配置或重启服务。

## 实现范围

基线 `e32eca51`；初始提交 `35ec8927`，复核修复提交 `7526f83a`。
沿用隔离工作区 `role-memory-qualification/Girl-Agent`。

即时模型保持现有 `deepseek-flash`（配置中的 V4.1 路由标识）；没有改它的参数、
交互截止时间或同步审核政策。代理模型为 `gemini-3.8-flash-medium`、Anthropic
Messages 协议。代理名称与 token 数是代理声明，不是独立上游身份/账单证明。

后台路由覆盖世界作者、NPC、事实提取、生活选择/刺激解释、反思、单条与批量
历史记忆保留、整理/撤回判断；生活来源审核与异步文本观察也使用独立后台时限。
普通 inbound、可见主动表达、插话重选、附件/外部感知注意、媒体选择保留即时路由。
这些分类按既有调用职责配置，不根据用户文字、动机或情绪硬编码选择角色行为。

CharacterInterior 仍是同一个逻辑语义作者；实际后台供应商与模型留在请求、结果
lineage和后台InnerTurn身份中。Core的纠正/Recall/来源校验继续工作，无跨供应商
自动回退。后台调用默认90秒；角色lease覆盖三次作者调用及每次独立Life审核预算。
事实提取旧8秒、Life审核旧22秒、异步文本观察旧30秒的外层上限均显式接线；
未启用混合配置时保留旧默认。

订阅请求用独立SQLite token账本发送前预留、结算、保留未知；重启后仍可读取。
不进入DeepSeek的人民币预留或debug账本。用户提供的5小时1.5亿、滚动7天5亿
作为本部署记录的额度上限；不声称覆盖其他客户端或账户全局消耗。

可加载配置：`configs/hybrid-background.env.example`，应作为现有配置之后的覆盖层。
代码默认仍是DeepSeek。启用这个候选配置会包含尚未通过兼容性验收的记忆整理，
因此不能把它当作已通过的生产发布配置。
