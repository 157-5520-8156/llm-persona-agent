# 未回复与负面情绪：归因和窄修复

## 生产证据

沿用生产只读副本 pin23979（2026-09-28 10:39:45 北京时间），没有查询失败时补零。
55条情绪记录中，各组件出现次数为：warmth54、joy17、sadness2、anxiety1、loneliness1；
未发现anger/hurt/resentment组件。组件次数不是互斥的情绪次数，也不等于角色真实情绪强度。
当前active只见warmth3920。

未回复评估有20个持久流程、205个受理尝试。通过receipt锚点精确关联到20次已保存的
world_stimulus_appraisal结果，而非把所有引用同一回执的调用都算作沉默评估。
多次既有解释围绕“我先开口的那一步已经落地”“关心递出去就够了”“不必用回复打分”。
所以不是完全没触发，也不是看板漏掉了大量生气记录。

## 原因

- 技术协议允许hurt/anger/sadness/loneliness/anxiety/resentment，并没有禁止负面情绪。
  当前人设也明确允许不高兴、不赞同、不用立刻安慰对方；继续堆“她有脾气”不足以定位问题。
- silence入口以旧ExecutionReceiptRecorded为锚点，但角色请求的context_note通用地描述
  “一个已提交变化”。模型多次将任务理解为“重新看待刚收到的送达回执”。
- 已有response expectation advisory重点展示最近一次邀请的等待时长；原例为约61分钟。
  在该保存请求的原pin核对完整时序：最后一条对方消息距今139230秒（约38.7小时），
  期间她已发出5组表达，第一组距今132091秒（约36.7小时）。新发一条消息不应使这段
  连续历史看起来又只剩一次短暂等待。
- 生产仍是9月26日启动的旧进程，前一轮发现的读取超时、高CPU问题没有在本轮用重启
  掩盖。本轮不把代码修复说成生产已经变化。

## 修改

新增纯读取的silence_observation，绑定当前World时间、原receipt、最后入站、同一角色与
发送目标。提供距最后入站/首组未回复表达/最近一组表达的时长，以及表达组数和锚点后
是否已有新入站。重复provider回执不重复计数，多Beat先按expression_plan合组；一组
表达中途得到回复后，后续Beat不被算作又一次主动联系。多人或缺失身份不提供误导计数。

仅在silence_appraisal capability中提供此材料，并改正该类调用的context_note：处理的是
当前持续回应空缺，旧送达回执不是对方的新反馈。未观察到回复不证明对方已读、故意忽略
或不在意。代码不选择情绪、强度、冷淡、追问或沉默，也没有增加情绪阈值或调用频率。

## 验证

- 保存的真实角色输入做候选级对照，移除两组共同的历史correction，其余输入/模型/工具
  一致。原输入2次均no_change且无affect_transition；仅补时序的2次分别提出
  loneliness1600+warmth4200、anxiety800+warmth5200。
- 最终时序+触发说明再做2次：均提出loneliness（2600、2400），同时保留warmth
  （4200、3200）。没有要求生成负面情绪，也没有得到anger，不能声称已验证“会生气”。
- 共6次真实调用，provider报告189610 input /3558 output tokens。原始请求、输出与用量
  留在`output/private-audits/silence-affect-20260928/`；没有往生产写入候选或发送QQ。
- 定向测试 **66 passed**，Ruff与diff-check通过。机械回归覆盖入站打断、原锚点过时、多Beat、重复回执、其他发送目标/角色、空身份，
  以及真实宿主装配、脚本化角色选择sadness/no_change、重启、effect-once和技术失败退避。
  修正旧测试只等lease而未等600秒技术退避的过时预期，不改变生产重试策略。

## 不能据此宣布解决的部分

真实模型试验只验证生成候选，未完成来源审核→情绪接受→后续聊天/主动联系的完整链条。
部分候选仍扩写“杯水”等缺少依据的物理细节；新时序摘要也不自动获得外部事实引用权限。
不能关闭来源审核来换取负面情绪。必须继续区分：自由生成未选择负面情绪、候选其他事实
不合法、来源读取缺口、情绪未接受、已接受但后续表达未使用。

下一项验收应在保持角色自主选择的前提下，对照“已说明忙碌”“普通闲聊无回音”与
“角色主动赋予较高重要性的期待落空”，检查解释、持久情绪和后续选择是否有区别；
不能设定“不回N次就生气”，也不能只以负面措辞出现次数作成功指标。
