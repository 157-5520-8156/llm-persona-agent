# 召回事实的引用与审核修复

范围：修复真实 Recall → CharacterInterior 作者权限 → 来源审核 → 回执重放的接口缺口。
发布状态仍为 `manual_only / qualification_incomplete`；检索命中率和模型语义判断另行验收。

## 原因与实现

自动预取已经把 Fact 交给角色，但原 Capsule 未选择该 Fact 时，作者没有相应引用权限；
来源审核的召回补充此前也只处理角色前史。只增加作者权限会让下一层继续失败。

此外，旧索引的 `text` 是整段 Observation 摘录，不一定是系统接受的事实值。
新 `hybrid.9` 保留既有 Fact／Observation 不可变绑定，用已有值哈希解析器读取
**已接受的精确值**，并呈现主体、谓词、状态和有效期。不会把同句的其他分句提升为事实。
无精确值绑定的旧记录不自动获得新权限。

同一个来源选择器校验可信 trace、原 cursor、角色、用户主体、隐私和作者实际读到的材料，
再把结果接入既有 `relevant_facts` 权限及 accepted Fact 审核协议。未展示、内容改变、
主体不符或缺少 trace 的材料不会扩展证据。Fact 的 Observation 仍是证明，不是可任意引用的事实。

原生提示词会可逆省略 `occurred_to=null`。新 Fact 审核先用已有 presentation 逆变换还原，
再做精确比较，避免把等价的真实阅读误判为未展示。历史 Fact 以唯一的接受事件作为可引用标识，
保留历史范围，避免索引内部复合 ID 与审核来源表不一致，也避免覆盖同一 Fact 的当前版本。

`.7/.8` 历史阅读、无新增字段记录的序列化和旧 prehistory 回执编译保持不变。
Fact 读取类型仅移到无循环依赖的叶子模块；旧导入路径、JSON schema 和序列化保持一致。
没有新增角色行为规则、检索排名方案或独立语义审核机制。
