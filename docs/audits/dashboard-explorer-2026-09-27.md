# Dashboard 运行机制与记录浏览

本次只调整只读看板，不修改角色的行为、生活结算或模型调用。新界面与现有
`world-v2-dashboard-home.1` DTO 共用同一数据源，遵循 ADR-0018 的字段可见边界。

## 已实现

- 可点击、支持键盘的 SVG 运行图：世界、记忆、感受与关系、角色决定、生活行动、
  表达联络、结果反馈、系统边界。每个节点有机制解释、真实摘要及不能据此推断的内容。
  连线明确是机制示意，不是某次运行的实际调用顺序或跨记录因果证明。
- 记录浏览器覆盖现有各领域的授权 highlights、闭合类别的技术 notices、未生效的
  关系变更摘要；按环节、类型、记录时间及文字筛选，分页展开正文、原有状态、来源领域、
  时间、数值和比例条。不会把计划转换为已发生的经历，也不把失败视为角色沉默。
- 覆盖范围入口提供各领域纳入/已知数量、截断状态、全部安全计数和资格说明。
  没有新增全部历史检索接口，搜索仍限于当前快照；不展示内部引用或私人反思正文。
- 展示此前页面忽略的表达模式和语义嵌入开关；保留完整领域视图与运维详情，但默认折叠。
- 暂停/恢复画面，录制时聚焦运行机制或记录浏览。暂停不暂停角色进程，已在途的响应
  不覆盖暂停画面。刷新保留节点、筛选和已展开的相同记录。

## 本机交付与限制

当前新版只读预览：`http://127.0.0.1:8790/dashboard`。

```sh
.venv/bin/python scripts/preview_world_v2_dashboard.py --port 8790
```

该脚本仅暴露现有 Dashboard 页面、脚本、快照、登录和退出路由，沿用 `.env` 的认证配置，
从原有 QQ owner 读取 DTO。没有重启 8787 的生产 QQ 进程，那里仍是旧版页面。

实际 owner 快照读取间歇性超时：既观察到约0.4秒成功，也观察到10秒以及单独45秒读取
超时；不能归因于新 UI。页面已验证保留最近成功快照并显示过期提示。生产接口响应稳定性
尚未修复，本次页面测试不代表上线资格通过。
