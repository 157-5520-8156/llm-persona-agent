## 下一验收顺序

1. 解决审核把候选句含义换成来源所能证明的较弱含义这一缺口。候选句的实际命题、问句前提和代词主体必须独立核对；不能只信模型自报的用途标签，也不能用关键词或本地固定句式替代语义判断。继续做成对正反例，不再凭单次通过提升资格。
2. 新审核先有可复查的正反例结果，才能进入带独立协议身份的聊天接线；保留旧请求和回执读取。随后再跑真实角色初稿、同角色纠错、审核、交付的完整链，保持普通交互截止。
3. 完成压缩记忆接受链，以及多日/多周性格、生活多样性、重复话题和成本验证。单元测试不能代替这些结果。
4. 邀请体验还需真实QQ终端回执、重启恢复、隔离与部署检查；录制还需三条演示主线和面板验收。小屋已弃用，不恢复角色移动。

先前“1–2天可录制、3–5天邀请体验”的估计依赖核心聊天问题迅速收敛，该前提尚未成立。当前没有足够证据给出可信发布日期。
