# 沈知栀：前二十年的连续生活增补

覆盖 **2005-04-12 出生至 2025-04-12 二十岁生日**。本次新增 **136 组生活阶段、1,064 个场景、1,037 条可读记忆、58,307 个正文字符**（含标点、不含元数据）。其中128组是主角亲历的密集阶段，8组是婴幼儿家史，分别保存后来听说的8条和未授予主角的32段世界层材料；5处私人理解独立于同场景的事件。

与原有222条前史合并后，隔离World共有 **1,259条**。严格截止二十岁生日的是 **1,238条**；原有5条时间区间跨过生日、16条在之后，均保留原样，不算作补齐前二十年的数量。规模不等于真人全部记忆，也不等于自由聊天已经能完整复述。

## 怎样交织

每个发生只有一个身份，短阶段、长期生活视图和具体人物故事通过引用同一记录交织。共有210条同分包源作者关系、62条跨分包关系，其中37条接入原有前史；此外还有5条同场景事件/私人理解的编译关联。8个生活长线视图和8个具体长期故事视图与密集阶段共享节点，不复制旧事实。

原2018年生日直接作为既有记录插入“生日之外的小纸条”阶段；许桥的旧协作矛盾、校刊改约与后来的交往变化仍引用原ID；旧纸盒、旧录音、母亲跳舞、书店与交换活动也有明确的后续或回指。仅主题相似的关系没有冒充明确回忆或因果。

作者标题不进入角色阅读，新增发生/段块/记录使用不含剧情词的稳定编号。角色不能靠编号里的“分开”“结局”等词猜未读内容。两个JSON知识时钟分别记录发生时间和获知时间；婴幼儿家史不能成为她当时的亲历。

## 可编辑来源和复现

`authoring/` 是本轮Codex原创源稿；`entities.json` 是新增历史身份；`weave.json` 是作者声明的关系和视图；`base-context.json` 冻结原来的World、传记和222条历史。`source-edits.json` 保留重要源作者修订。修改新稿后需重新编译并在新的初始副本采用，不能覆盖已经接受的原事件。

在本工作树运行，输出目录必须是新的：

```sh
PYTHONPATH=src python configs/prehistory/native-dense-life-20261008/build.py \
  --out-dir output/dense20-build
```

生成7个有顺序依赖的分包，每包不超过256条记录。完整的源、冻结上下文、编译凭据会保留在输出中；仓库提交可编辑原文和哈希清单，不重复提交每个大分包里相同的历史正文。`compiled-manifest.json` 固定本版结果；本次两次构建的23个输出文件逐字节一致。

编译和初始化没有作者供应商、retain/no_change或独立模型审核调用。Codex这次写作/工程会话自身的成本不在原DeepSeek实验账本中。聊天的模型输入和Recall阅读预算没有扩大。

## 安装与验证

安装需从包含冻结基线的已有World复制，不能拿来覆盖另一个角色或历史。安装器只允许写本工作树的`output/`下的新目标，支持同一冻结包和目标的中断恢复；调用既有公开档案接纳与直接初始化接口，逐32条报告进展，最后重复面向用户的安装接口验证幂等。

```sh
PYTHONPATH=src python configs/prehistory/native-dense-life-20261008/install.py \
  --packages output/dense20-build \
  --source output/private-audits/direct-memory-parity-20261008/world.sqlite \
  --database output/dense20-validation/world.sqlite \
  --report output/dense20-validation

PYTHONPATH=src python configs/prehistory/native-dense-life-20261008/verify.py \
  --packages output/dense20-build \
  --database output/dense20-validation/world.sqlite \
  --output output/dense20-validation/checks
```

本版实际采用库：`output/private-audits/dense-life-twenty-years-20261008/accepted-world/world.sqlite`。新1,037条全部active；旧222条记录和381个候选的哈希保持不变。重复安装不增加事件。152个含新记录的视图经360页公共读取全部可达；世界层、其他actor、转述获知时间与原文完整度均已验证；39,895事件的冷回放hash一致、无findings。

后续普通聊天应从这个库另开副本，使用现有 `scripts/chat_with_world_v2.py --clone ... --database ...`，显式加载与实际使用一致的设置文件。只输入用户问题，材料由系统检索。首次创建副本才传`--clone`，继续已有会话时不再克隆。本轮没有直接给DeepSeek喂整本书做“通过”判断，也没有继续修改检索性能机制。
