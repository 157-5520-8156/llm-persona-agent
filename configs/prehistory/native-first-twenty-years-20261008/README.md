# 沈知栀：前二十年人生底稿

主体从 **2005-04-12 出生至 2025-04-12 二十岁生日**。保留既有的嘉兴成长、母亲沈岚、父亲经营书店、2024年高中毕业及9月大学入学等基础，不采用早期已废弃的2023年入学版本。

这是一份完整分期的虚构人生源稿及可重复编译包。它不是每一天的流水账，也不把她写成已经完成成长、以后只会按一个性格公式行动的人。未来仍由运行中的角色选择；原稿中的“她当时这样想”不等于她现在必须如此。

## 从哪里读

- [life-story.md](life-story.md)：优先读这一份。按六个人生时期合读新旧正文，隐去技术编号，保留时间区间和婴幼儿世界层标记。
- [life-reading.md](life-reading.md)：全部新增场景原文，再列既有历史、日期跨越生日的旧记录及二十岁后的衔接。
- [chronological-reading.md](chronological-reading.md)：将新旧内容按发生区间放在同一阅读时间轴；保留旧记录原有的不确定日期。
- [storyline-map.md](storyline-map.md)：几条长期变化、交织处和仍未确定的事情。它供作者理解内容，不进入角色提示词。
- `source.json`：权威原生源。59个场景、122个段块，约1.25万字新增正文。
- `coverage.json`：结构覆盖数据；数量和标签重叠不等于叙事质量的证明。
- `source-edits.json`：明确的源作者修订，包含人物串线、物件身份、错误连接和已解决问题的清理。
- `authoring-context.json`：冻结的既有基础；`compiled-package.json`：据此纯编译的采用候选。
- [qualification.json](qualification.json)：实际采用、角色自主保留、来源检查、费用和未通过的复述案例。

## 与原有世界的关系

新增118条主角可读记录；4个婴幼儿世界层段块不授予主角记忆。她后来听父母讲旧事的过程另有2010年的场景，不能把出生那天写成自己亲眼记得。

原有72条历史原文和身份不变：51条的整个日期区间在二十岁生日以前，5条区间跨过生日，16条属于之后的既有衔接。后两组不能为了凑齐“前二十年”而改日期或假装提前知道。

每个场景只有一个发生身份，可以参与多条故事线；人物私有理解仍各归其主。林夏、罗嘉禾等在本稿中是历史身份，源稿导入不会自动把她们创建成活跃NPC。

## 编译与采用

在项目根目录运行：

```sh
PYTHONPATH=src python scripts/compile_native_story.py compile \
  --source configs/prehistory/native-first-twenty-years-20261008/source.json \
  --brief configs/prehistory/native-first-twenty-years-20261008/authoring-context.json \
  --archive-id prehistory-archive:celia-first20-native-20261007 \
  --out-dir output/native-life-compile
```

编译不调用模型、不改World。采用使用编译回执，不伪造独立审核通过；既有审核包继续有效。导入与角色自主保留是两步：角色可以保留、略过，以后也可以遗忘。重复导入同一包不重复创建历史。

本稿已在隔离World完整导入，角色自主保留117条、略过1条；全部117条active记录可显式读取，重复导入不重复写入，冷回放通过。**未写入生产库，未接通真实QQ**。

自动复述尚未通过语义验收：纸盒问题有检索遗漏与无据否定；相册问题曾遇到来源连接错误，修复后仍出现说话者归属和未知结局的改写。源稿完成与自动复述完全可靠是不同结果，运行资格仍为 `manual_only / qualification_incomplete`。完整证据见[验收记录](../../../docs/audits/native-first-twenty-years-2026-10-08.md)。

随后完成的[场景读取与复述对照](../../../docs/audits/scene-recall-and-retelling-2026-10-08.md)已改善上述检索和父母说话归属问题，但仍有无据的数量、当前状态及“最早记忆”判断；正确证据下也未全部消失。源稿与117条保留结果未重做。本轮新增4次远程调用，已知估算CNY0.088050；`qualification.json` 保留首次导入验收时的费用快照，最新累计费用见后续对照记录。

## 创作与费用口径

来源作者为专用调试供应商的 `deepseek-v4-pro` 与本轮Codex源稿编辑，使用冻结历史分六段创作。首轮Flash不合格稿、结构修正、未通过的连接修正和预算拒绝均保留；未把失败调用隐藏为成功，也没有追加独立模型复审流水线。

源稿写作与结构修正共13次实际供应商调用，按返回token和配置价格估算 **CNY1.463238**，未知费用请求0。这是供应商接口估算，不包含Codex编辑会话本身的订阅或token费用。角色保留、实际读取及本地embedding分别计入验收记录，不能声称上述金额包含一切。
